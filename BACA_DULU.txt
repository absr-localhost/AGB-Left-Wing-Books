LANGKAH (HP)
1. Repo > Add file > Upload files. Ekstrak ZIP, unggah SEMUA isinya (timpa). Commit changes.
2. Tab Actions > Build APK. Lihat langkah "Unduh isi buku": Berhasil dan Dilewati.
3. Terjemahan: Actions > Terjemahan mesin > Run workflow ("semua" atau satu id).
Jika .github tidak terunggah: Add file > Create new file, nama .github/workflows/build.yml (isi dari ALUR_KERJA_build.yml) dan .github/workflows/terjemah.yml (isi dari ALUR_KERJA_terjemah.yml).
